# NetHunter AnyKernel3 Installer for Xiaomi SM6250 (Miatoll)

Flashable AnyKernel3 configured for Kali NetHunter on Miatoll devices running LineageOS 22.2 (Android 15).

## Supported Devices

* **Redmi Note 9S / Redmi Note 10 Lite** (`curtana`)
* **Redmi Note 9 Pro (Global)** (`joyeuse`)
* **Redmi Note 9 Pro Max (India)** (`excalibur`)
* **POCO M2 Pro** (`gram`)


## Notes

* Kernel modules are loaded systemlessly through the AnyKernel3 helper module when Magisk or KernelSU is detected.
* No ramdisk modifications are included, only the kernel image and modules are flashed.
